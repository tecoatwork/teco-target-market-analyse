# Teco Export Market Decision

面向外贸供应商的市场进入决策 Skill：从产品和目标国家出发，研究采购需求、竞争替代、供应能力与商业条件，形成可追溯的判断和下一步验证建议。

它是一组供支持 Skill 的 AI 助手读取的工作指令，不是独立运行的市场数据库或自动爬虫。

## 适用场景

- 判断某产品是否值得在某个国家开展小规模市场验证。
- 比较多个国家的客户、渠道和进入障碍。
- 在客户开发前梳理采购要求与自身能力差距。
- 对已有市场判断寻找支持证据和反证。

不负责单个客户身份背调、持续监测、自动联系客户或发布营销内容。

## 工作流程

1. 确认产品、国家、目标客户与需要作出的决定。
2. 查找当地采购理由、条件、替代产品及渠道证据。
3. 对照供应商的报价、MOQ、交期、技术资料和服务能力。
4. 区分事实、计算、推断和未知信息，检查样本与价格口径。
5. 给出有条件的判断，以及最多三项优先验证行动。

默认输出紧凑的决策备忘录；明确要求深入研究时扩展调查范围。

## 环境要求

- 支持读取 `SKILL.md` 的 AI 助手；包含 Codex 界面元数据。
- 核验当前市场信息需要可用的搜索和网页阅读能力。
- 无需 API Key 配置脚本、额外 Python 包或其他私人 Skill。
- 没有联网工具时，可分析用户提供的材料，但不能声称已完成最新市场核验。

没有硬编码个人目录、公司知识库或专用账号。输出语言随用户请求，默认沿用对话语言。

## 安装

### 通过 Codex 安装

将下面的安装指令发给 Codex：

```text
请使用 skill-installer 安装这个 GitHub 仓库中的 teco-target-market-analyse Skill：
https://github.com/tecoatwork/teco-target-market-analyse
```

此仓库根目录就是 Skill 目录；使用安装器时应定位根目录的 `SKILL.md`。

### 手动放入本地技能目录

将整个仓库目录保存为技能目录下的 `teco-target-market-analyse` 文件夹。Codex 常用的个人目录是 `~/.codex/skills/`；自定义环境请使用实际配置的目录。

确保目录结构是：

```text
teco-target-market-analyse/
├── SKILL.md
├── agents/
│   └── openai.yaml
├── README.md
├── COPYRIGHT
└── LICENSE
```

安装后重新打开会话；若未发现技能，重启客户端并检查路径。

## 使用示例

### 市场初筛

```text
$teco-target-market-analyse
帮我评估不锈钢厨房水槽进入沙特市场的机会。
重点研究进口商和厨房设备经销商，先做初筛。
没有提供的自身能力信息请标为未知。
```

### 带供应商条件的评估

```text
$teco-target-market-analyse
评估我们的装饰墙板在德国经销商渠道的开发价值。
以我附上的产品规格、报价和交期资料为依据，
对比采购要求，列出最需要验证的三个问题。
```

### 多市场比较

```text
$teco-target-market-analyse
比较同一产品在法国和西班牙的进入条件。
采用相同客户类型和价格口径，不同口径的数据请分开说明。
```

## 建议提供的资料

至少提供产品与目标国家。目标客户、应用场景、价格及贸易术语、MOQ、交期、技术文件、定制和售后能力有助于提高判断质量；缺少这些资料不代表供应商没有能力。

## 交付内容

- 开发建议及成立条件。
- 目标客户、采购场景和候选产品方案。
- 有来源的依据、反证与局限。
- 自身能力差距和商业条件。
- 可执行的优先验证任务。

文件仅在用户要求时生成，不自动写入知识库或覆盖已有报告。

## 使用边界与验证状态

公开信息可能不完整。该 Skill 不保证市场成功，也不将零售差价视作出口利润。相关监管与准入判断需核对产品、用途、地区和有效时间。

创建本发布包时已检查文件结构、YAML 格式、个人路径和私人依赖；尚未进行真实市场调研的端到端试跑。不同模型及联网工具可能产生不同执行效果。
